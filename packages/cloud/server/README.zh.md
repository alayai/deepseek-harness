# @deepseek-ai/dsh-cloud-server

[English](README.md) | 中文

## 概述

使用 DS Bot 团队侧栏时，点击侧栏底部的「DSH 云端」即可登录或重新打开云端资源。

通过 DSH 云端入口登录 dsh-server，即可操作云端资源。开始登录时，系统停止本地任务，并要求身份服务重新验证身份。Worker 不可用时，受影响的操作会失败，但仍可选择租户和工作空间。登录过期或被撤销时，云端访问暂停，直到重新登录或显式退出。两种情况都不会自动切换到本地执行。

## 使用本包

内置 Web 组合为 Web 与 Desktop 客户端挂载本包。在仓库根目录运行 `pnpm run dev:web` 或 `pnpm run dev:desktop`，然后打开 **DSH 云端**。有会话显示时，左侧导航底部状态入口打开现有右侧栏；没有会话时，打开云端管理页。左侧导航也提供管理页入口。关闭或隐藏这些视图不会退出登录，也不会恢复本地执行。填写 dsh-server 的源地址，例如 `http://localhost:17800`，并在浏览器窗口完成统一账号登录。服务端必须提供面向 `dsh-desktop` 公共客户端的原生 PKCE 发现端点。

远程服务使用 HTTPS；HTTP 仅用于回环开发地址。完成登录的浏览器必须能访问 Host 所在机器的回环回调地址。远端 DSH Host 与另一台机器上的浏览器需要其他回调传输方式。

刷新并选择租户和工作空间，再刷新资源。沙箱、会话、文件、私有桌面、任务和设置按分区展示。分配并启动沙箱后，即可提交云端命令。设置区域保存云端模型凭据，并提供当前服务器允许的 Aiconvert 和 DeepSeek Demo 模板；选择模板会填入接口地址和模型名，并清空密钥栏，密钥仍需由你单独输入。工作空间模型独立于沙箱和桌面加载。读取失败可重试，尚未配置模型时可进入云端模型设置。会话区域创建云端会话。文件操作使用所选沙箱中的相对路径。RustFS 上传仅传输用户明确选择的文件。桌面区域通过截图、输入文字与离线浏览器请求分配和控制云端桌面。

在**文件**中可编辑不超过 16 KiB 的 UTF-8 文本。若未收到保存回执，请用同一账号重连并重新打开同一沙箱，选择**查询原保存任务**。查询不会重新写入文件。草稿保留在当前客户端，退出登录或重新加载后清除。保存被取消、超时或发生版本冲突时，请先复制草稿，再重新打开文件对照。发布到 RustFS 前请核对显示的源文件路径；发布使用该次读取的内容。

在云端模式下打开 **云端资源 → 会话**，创建或选择会话，再点击 **前往云端会话**。主界面列出当前工作空间的云端会话，可直接向 dsh-server 发送文本；Enter 发送，Shift+Enter 换行。也可以从主界面返回云端资源。

云端会话复用 DSH 的消息输入框、用户气泡、Markdown 和可展开的工具卡片。按云端 Bot 筛选会话不会改变已固定的版本。启用 DS Bot 时，由它的侧栏和聊天组件展示云端会话。创建 Bot 后会选中新 Bot 以便新建会话，已有会话的绑定保持不变。请在会话区选择运行中的沙箱和模型凭据。工作空间没有沙箱时，可直接点击**分配沙箱**；所选沙箱已停止时，点击**启动**。私有桌面可留空。未启用该界面时，仍可用 **原生聊天布局** 切换显示方式。任务页按所选沙箱分页，最近一页会自动刷新。

服务端固定每个会话的沙箱、模型凭据、可选桌面及可选的已发布工作空间 Bot 版本。主聊天校验并提交绑定版本，浏览其他资源不会改写执行目标。更换资源请新建会话。“取消任务”只请求停止，主聊天继续查询原任务，直到服务端确认结果。 重新登录同一服务器和账号后，客户端可以按原请求编号查询丢失的回执。暂时查不到回执不能证明任务未入队，查询不会重发消息。客户端重启会清掉本地请求编号；新版 API 会随会话绑定返回排队中、执行中或结果未知的任务。结果未知时须核对原任务或另建会话。

展开 **本地历史与 Bot · 只读**，按需读取 Host 本地预览。会话列表仅显示 ID 和创建时间；明确选择后展示用户及助手文本，先显示最新一页。工具载荷、推理、请求头、附件和工作目录不包含在内。DS Bot 通过 `ctx.botReadOnly` v1 提供已加载团队的名称、角色、有限长度的指令和模型引用；隐私配置仅对 Host 所有者展示。公开 Bot 另有独立的 `dshCloud/exportLocal` 操作，只有用户明确点击后，才会把完整名称、角色和指令复制到选定的工作空间；后续本地修改会在复核后追加不可变云端 revision。客户端只持久化服务器、用户、租户、工作空间、Bot ID、revision/version、摘要和时间，不保存指令、凭据、文件、记忆、历史或 token。隐私 Bot、模型凭据、目录、技能、连接器、记忆和历史永不导出。服务缺失或尚未初始化时明确提示，查看不会加载或刷新团队。你曾输入的文本可能含敏感信息。预览不会上传、写入云端提示或在本地继续执行；云端暂停时仍可只读，连接版本变化后丢弃旧结果。通过 **前往云端会话** 另选资源、新建独立会话。

登录期间、云端使用中和云端暂停时，仍可查看本地插件列表、选择目录，以及把已选择的现有目录登记为工作区。选择目录只有在你明确提交工作区操作后才会创建本地工作区，也不会向服务器传输文件。本地插件安装、移除、更新、启停变更、创建目录、重命名或删除工作区以及 Agent 或工具执行仍被阻止，直到退出云端并返回本地模式。

点击“退出云端并返回本地”恢复本地使用。本地任务排空失败或服务端撤销登录未得到确认时，本地执行继续被阻止；相关服务恢复后可重试。Client 在内存中为每个工作空间保留最近提交的任务引用，视图关闭重开后仍可使用。“查询原任务”只读取同一任务，不重新提交。接收响应丢失时保留幂等键和请求路径。登录、退出、Client 刷新和插件卸载会清除此临时索引。服务端任务历史是权威记录，任务不会重放或复制到本地 DSH。

直接上传前，RustFS 桶的 CORS 规则必须允许 DSH 页面的准确源地址。将该地址加入 dsh-server 的 `CORS_ORIGINS`，再在服务端仓库运行 `pnpm storage:init`。DSH 端口不同即属于不同的源，无需使用通配符。

超过 8 MiB 的文件使用 RustFS 分片上传。客户端只在浏览器本地保存有界的上传回执：服务器/用户/租户/工作空间范围、对象 ID、文件名、大小、过期时间，以及由固定大小分片摘要组成的 SHA-256 指纹；不会保存预签名 URL、bearer token 或文件字节。若重新加载后仍缺少分片，重新选择同一文件即可校验指纹并补传。不同文件会在查询服务端会话前被拒绝；过期回执可以在面板中清除。

客户端同时上传最多三片。分片 PUT 遇到网络错误、超时或临时 HTTP 故障时，该分片最多重试两次，每次重新获取签名 URL。暂停会取消正在进行的 PUT 和等待中的重试。若有分片无法上传，客户端保留会话供续传，不会发起合并。

默认的同步上传在传完后由服务端检查并发布。扫描繁忙、不可用或完成响应丢失时，选择「重试发布」，可对同一对象重新请求完成，无需再传文件。安全扫描拦截后，放弃该分片上传或清除小文件选择。发布重试入口只在当前面板内保留；重新加载后，恢复同步分片上传仍须重新选择原文件。

文件超过 8 MiB 且不超过服务端公布的上限时，可勾选**先在后台扫描，再发布文件**，传完后进入队列。默认不勾选；连接旧版服务端时沿用同步流程。如果浏览器已保存未过期回执，在同一浏览器使用原服务器、账号、租户和工作空间重新打开原目录，点击**查询发布状态**即可读取原对象，无须重新选文件或上传。若所有分片已传完，但服务端确认尚未入队，可点击**提交已上传的分片扫描**。只有发布成功后才能下载。

在 **云端文件 → 工作空间文件** 中浏览目录、上传到当前目录、下载已发布的文件。有工作空间写权限时，可以新建目录、重命名、移动、删除空目录，以及将文件移到回收站或恢复。遇到版本冲突或无法确认修改结果时，先查看刷新后的列表，再决定是否重试。

登录要求 server-info 声明云端协议 1，且客户端版本范围包含 1。协议缺失或不兼容时云端目标暂停，已签发权限保留以供明确退出。设置 → 版本诊断只读查看 API 和 Worker 报告。Worker 就绪状态分别控制执行功能；功能未就绪不会恢复本地执行。请在维护窗口同步升级 API、Worker 和 DSH Host/Client；登录检查无法保证混用旧 API 节点时的安全性。

### 组合配置

本包没有插件配置字段。应用通过 API Remotes 选择其生成的 Remote，并通过以下配置行挂载 Host 与 Client 两部分。本包未声明配置层 bundle；dsh-server 服务压缩包也不是需要安装到 Desktop 的插件。

```yaml
- name: "@deepseek-ai/dsh-cloud-server"
```

## 理解实现

<details>
<summary>实现细节——点击展开</summary>

Host 负责 PKCE、临时回调监听器、访问令牌、登录代次和上游请求。Renderer 仅获得展示状态与有大小限制的 JSON。云端目标被保留期间，API Gateway 守卫、连接请求瀑布、工具守卫和 Agent 步骤前钩子共同阻止本地准入。登录会等待活动 Agent、终端、Job、已准入的 Remote 调用和已跟踪 HTTP 处理器结清。

每个业务请求携带当前展示代次和工作空间路径。代次变化后，旧结果会被拒绝。网络错误、认证拒绝与过期会暂停云端目标。退出操作串行执行，在客户端异步任务结清且服务端确认撤销或令牌已知过期后才恢复本地准入。重连先撤销旧授权，再获取新授权。

这些机制是应用层准入控制，不是针对受信任 Host 插件的操作系统沙箱。服务端租户授权与运行环境隔离仍由 dsh-server 负责。

| File | Responsibility |
|---|---|
| [connection.ts](src/connection.ts) | 执行目标生命周期与授权所有权 |
| [index.ts](src/index.ts) | Host Remote 与本地准入 |
| [local-read.ts](src/local-read.ts) | 仅所有者可读的有限本地展示数据，不激活 Agent |
| [CloudChat.tsx](src/client/CloudChat.tsx) | 云端主聊天、历史与消息入口 |
| [CloudPanel.tsx](src/client/CloudPanel.tsx) | 云端资源操作界面 |
| [CloudObjectBrowser.tsx](src/client/CloudObjectBrowser.tsx) | 工作空间目录、已发布文件与回收站 |
| [upload-resume.ts](src/client/upload-resume.ts) | 有界的浏览器本地分片回执与分片指纹 |
| [multipart-transfer.ts](src/client/multipart-transfer.ts) | 并发分片上传、有限重试与取消 |

</details>

## 模型体验

### 云端提示词

#### 模型看到什么

用户向所选云端会话提交 `prompt` 提示词。dsh-server 负责该会话的模型上下文与工具。本包不添加本地模型提示词或工具 schema。

#### Token 影响

提交文本进入云端请求；历史与截断由服务端控制。状态轮询和资源操作不会增加本地模型 token。

#### KV Cache effect

云端会话独立于本地会话。缓存复用由 dsh-server 与所选模型提供方负责；切换云端会话会改变请求上下文。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

云端视图具有以下限制。

- 云端会话展示供应商 SSE 的持久化文字增量，最终消息覆盖临时气泡；工具调用与结果按任务及调用 ID 合并，详情可折叠。事件与游标在同一 Client 内存缓存中原子更新，跨会话页面重开恢复；刷新 Client 从服务端重读，不能仅凭旧游标跳过历史。缓存最多 4 个会话，每会话 2,000 项及约 200 万 JSON 字符。云端历史不写入本地 Session。
- 导航和最近任务引用在同一 Client 生命周期内跨面板关闭保留，刷新或重新登录会清空。关闭视图取消本地上传和轮询，不会取消已接收的云端任务。不同窗口分别维护视图状态。
- 沙箱命令、启动或停止请求丢失响应后，在原工作空间和沙箱点击**查询原任务**。面板用原请求键读取回执，再读取任务状态；查询不会重新提交操作。查不到回执不能证明任务没有执行。同一窗口重连原服务端和账号后仍可查询；退出云端、切换服务器或刷新客户端会清除内存中的编号。此功能需要带沙箱任务回执接口的服务端 API。
- 点击**加载更多工作空间**可以继续查看同一租户的工作空间。在主聊天或资源面板点击**加载更早的会话**，每次追加 20 条，当前对话不变。点击 Bot 会保留当前与它绑定的会话，或打开它最近的可见会话，即使该对话已不在工作空间最近 100 条内。此功能需要新版会话分页 API；旧服务端最多返回 100 条，不能据此确认更早的 Bot 对话不存在。云端事件不写入本地 Session。
- 如果服务端确认原先选中的会话已不可见，点击 Bot 仍能打开它最近的可见对话。若查询失败或返回的会话编号不符，保留原选择。等待查询时从侧栏进入云端资源，查询返回后也会停留在资源面板。
- 工作空间模型设置页和新建会话表单都支持**加载更多模型**。每次最多追加 20 条当前账号的模型凭据；读取失败时保留列表和当前选择，点同一按钮即可重试。连接旧 API 时仍可查看最近 100 条凭据，更早的凭据需要更新 API 后才能查看。
- 文件页可把成功的 Sandbox 文件读取结果明确发布到 RustFS，并展示来源任务与下载入口。响应丢失后保留原幂等键供明确重试；产物回执仅在 Client 内存保留。产物受 16 KiB 大小限制和服务端发布要求约束。
- 分片回执只保存在浏览器本地。补传需要重新选择原文件；查询异步发布状态不需要。校验按每次 8 MiB 读取，浏览器没有 Web Crypto 时不能恢复已保存回执。真实网络性能、容量和 Windows 安装版 Desktop 仍待验收。
- 桌面页可通过 Host 的回环 noVNC/WebSocket 桥打开交互窗口；上游 bearer 和票据保留在 Host。窗口地址含短效随机访问能力，只能在 Host 所在机器打开；暂停或退出关闭桥。没有把桌面视频嵌入侧栏。
- 切换浏览的沙箱会清除私有桌面选择。选中桌面后，面板先核对它所属的沙箱和运行状态。已停止的桌面可启动；连接、截图、输入和浏览只能对已确认运行的桌面操作。若在别处改变了桌面状态，点击**重新核对桌面**。请求途中切换目标时，迟到的查看器地址和截图不会进入新桌面；服务端已经接收的任务仍会继续。
- 配合更新的 API/Worker 与 `dsh-agent:0.4.2`，绑定桌面的 Agent 获得受限 `cloud_computer`/`cloud_browser` 工具，未绑定会话不注册；浏览器仍使用离线策略。模型截图附件与真实视觉任务尚未实现，完整本地 Bot 适配仍有后续工作。
- 访问令牌仅保存在 Host 内存，没有持久刷新令牌。重启 Host 会开始新的本地会话，不会恢复云端授权；已有 Client 需要刷新页面以重新建立状态。
- 准入控制覆盖已注册的应用路径；直接访问操作系统的受信任插件需要额外隔离。Windows 安装版 Desktop 验收独立于 Web 验证。
